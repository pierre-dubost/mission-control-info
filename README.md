# Dashboard / Mission Control — public information

Static public information pages for the private personal-use Dashboard / Mission Control application.

This repository contains **only public explanatory documents**. It must never contain application source, credentials, account configuration, message/event/task data, caches, logs, private policies or screenshots of actual account information.

## Pages

- `index.html`: app identity, functionality and purpose of Google access.
- `privacy.html`: access, local storage, external AI processing, retention/removal and site hosting.
- `terms.html`: personal use and application limitations.
- `style.css`: local stylesheet; no third-party dependencies or JavaScript.

Publish through GitHub Pages using the `main` branch, root (`/`) folder, with HTTPS. Keep this repository separate from the private application repository. Do not enable public issues or invite users to submit account data here; use the contact address on the site.

Publishing these documents does not itself change Google OAuth publishing status, complete provider verification, reconnect accounts or deploy the application.
