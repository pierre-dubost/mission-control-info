A private daily briefing.

Dashboard, called Mission Control inside Hermes Desktop, is a private tool operated by Pierre Dubost. It brings selected email conversations and calendar events into one local briefing.

What the application does

It highlights potential actions, questions to confirm, items waiting on others and relevant developments. A rolling agenda shows upcoming events. Findings link back to their original sources so the user can check the evidence.

Optional access to approved Discord conversations supports the same private briefing. This website does not provide access to the application or its data.

Why it asks for Google access

Read email
Read selected Gmail conversations, including message text and headers, to identify possible follow-ups and provide source evidence.
Read calendar information
Identify available calendars and read events from the calendars explicitly selected for the briefing.

The Google connection is read-only. It does not send, delete, archive or mark email as read; it does not edit events or respond to invitations.

Local application, with AI processing

Source copies, findings and saved handling decisions are stored in the operator’s local application environment. Selected email or Discord text and relevant review instructions are sent to the AI provider configured in Hermes to generate the briefing. Processing is therefore not entirely on-device.

Optional completion notes and decision history are kept out of AI review input. See the privacy policy for data access, sharing, retention and removal details.

Use and limitations

This is a personal-use application, not a public account service. Coverage is bounded and AI-generated conclusions can be incomplete or wrong. Marking an item Done records a local decision; it does not perform the underlying work.
